# BitClock legal pages

The privacy policy, terms of use and support page of the BitClock app, in English, German, Spanish, Portuguese and Bulgarian, published with GitHub Pages:

| | English | Other languages |
|---|---|---|
| Support | https://n100yanov.github.io/bitclock-legal/ | …/bitclock-legal/de/ · /es/ · /pt/ · /bg/ |
| Privacy policy | …/privacy-policy.html | …/de/privacy-policy.html and so on |
| Terms of use | …/terms-of-use.html | …/de/terms-of-use.html and so on |

The app opens the page in its own language, so keep the file and folder names. Every page has the language flags at the top (`_layouts/default.html`).

**Contact form:** put the Web3Forms access key in `_config.yml` (`contact_form_key`) to show the form on the support pages. Web3Forms keeps the e-mail address it forwards to on its side, so no address is ever shown here.

The source is `docs/legal` in the app's repository.
